# rpi-facerecognition-frame
Raspberry Pi based photo frame that detects person infront of the camera and shows photos of the same person from the pre-uploaded album.

# Prerequisites 

sudo apt-get install python-dev libatlas-base-dev libopenjp2-7 libtiff5-dev libilmbase23 libopenexr-dev python-opencv

wget https://github.com/GregDMeyer/IT8951/archive/master.zip
unzip master.zip 
cd IT8951-master/
pip3 install -r requirements.txt
pip3 install ./
